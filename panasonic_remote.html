Server Mode Use when direct mode is blocked by browser security
Server mode requires running node panasonic_server.js on a computer in your home network, then browse to that computer's IP on port 8080.
📱 Share with family: Once the server is running, share http://YOUR-PC-IP:8080 with anyone on your home WiFi — no app install needed!

💡 Tip: Assign a fixed IP to your TV in your router's DHCP settings so the address never changes.
